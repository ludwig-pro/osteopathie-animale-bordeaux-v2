# Paysage concurrentiel organique

## Méthode

- **Date** : 19 juillet 2026.
- **Zone** : France, langue française, navigation de bureau non connectée.
- **Source SERP** : Brave Search France ; les annonces et le local pack ont été
  exclus, seules les cinq URL organiques du snapshot ont été consignées.
- **Complément qualitatif** : Google Autocomplete avec `hl=fr&gl=fr`. Ce signal
  ne fournit aucun volume.
- **Outil SEO** : API publique Ahrefs pour le Domain Rating (DR) observé au
  niveau du domaine.
- **Domaines référents** : indisponibles publiquement dans une vue comparable.
- **Backlinks** : indisponibles publiquement dans une vue comparable.

Les rangs ci-dessous décrivent un échantillon Brave ponctuel, pas une position
Google ou Search Console stable. Un nouveau passage Brave a déclenché un
CAPTCHA. Deux URL historiques étaient inaccessibles lors du contrôle ; leur
présence dans le snapshot est conservée comme limite, sans leur attribuer de
preuve actuelle. Les descriptions synthétisent le type de contenu observé sans
en copier le texte.

## Lecture pour la décision

L'existence de pages espèces ou locales chez des concurrents ne prouve ni une
demande suffisante ni une conversion. Le site actuel apparaît déjà sur les cinq
intentions du snapshot. En l'absence de volumes, de conversions par page, de
Domaines référents et de Backlinks comparables, cette photographie ne résout
pas la cannibalisation et constitue un veto à la génération de nouvelles
routes.
